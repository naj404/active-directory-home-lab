# Active Directory Home Lab (Windows Server 2022)

## Overview
This project demonstrates a hands-on Active Directory lab using Windows Server 2022 hosted on Amazon EC2.
The environment simulates a small enterprise network where centralized user management, Group Policy enforcement, NTFS permissions,
and remote access were configured and tested.

## Features
- Domain Controller deployment
- Organizational Units (HR, IT, Devices)
- User and Group management
- Group Policy (password + control panel restriction)
- NTFS File Shares
- RDP access for domain users
- Event Viewer login auditing

## Technologies
- Windows Server 2022
- Active Directory Domain Services
- Group Policy
- NTFS Permissions
- Remote Desktop
- Event Viewer
- Amazon EC2 (AWS)
- Basic VPC / Security Group networking

## Skills Demonstrated
- Identity Management
- Access Control
